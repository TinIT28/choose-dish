# 04: Món dùng chung và personal exclusion

**What to build:** An admin can manage the shared dish catalog and manually reset a user's password. Any authenticated user can browse shared dishes, copy one into their independent private catalog, or hide it from their own random pool.

**Blocked by:** 02: Đăng ký, đăng nhập và session theo thiết bị; 03: Quản lý món riêng với ảnh bắt buộc

**Status:** ready-for-agent

- [ ] Only admins can create, update, deactivate, or delete shared dishes.
- [ ] A user can read active shared dishes and copy a shared dish into an independent private dish.
- [ ] A personal exclusion hides a shared dish only for its owner and can be added or removed.
- [ ] Admins can reset a user's password without seeing that user's private dishes or selection history.
